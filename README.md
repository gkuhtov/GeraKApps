## 🧭 О проекте

**GeraKLab** — приложение для iPhone с набором интерактивных экспериментов, сенсорных эффектов и игровых инструментов. Проект объединяет лабораторию, случайные сценарии, избранное, историю запусков и настройки.

Репозиторий содержит исходный код приложения на Swift и SwiftUI, ресурсы экспериментов и сценарий автоматизированной сборки.

## ✨ Основные возможности

- 🧪 **Лаборатория** — каталог интерактивных экспериментов.
- 🎲 **Случайный режим** — запуск случайного сценария.
- ⭐ **Избранное** — быстрый доступ к выбранным экспериментам.
- 🕘 **История** — просмотр предыдущих запусков.
- 📳 **Системные возможности iPhone** — работа со звуком, датчиками и другими доступными возможностями устройства в рамках реализованных сценариев.
- 🎨 **Интерфейс в стиле GeraK** — собственная система оформления и навигации.

Доступность отдельных функций зависит от устройства, версии iOS и выданных разрешений.

## 🧱 Структура проекта

| Путь | Назначение |
|---|---|
| `GeraKLab/App/` | Точка входа и корневой интерфейс |
| `GeraKLab/Core/` | Общие компоненты и система оформления |
| `GeraKLab/Models/` | Модели данных и элементы интерфейса |
| `GeraKLab/Resources/` | Конфигурации и данные экспериментов |
| `GeraKLab/Services/` | Работа со звуком, датчиками, историей и логикой экспериментов |
| `GeraKLab/Views/` | Экраны приложения |
| `.github/workflows/build.yml` | Сценарий сборки в GitHub Actions |
| `project.yml` | Конфигурация проекта для XcodeGen |

## 🛠️ Технологии

- Swift и SwiftUI
- iOS; целевая версия задаётся в конфигурации проекта
- JSON для описания экспериментов
- GitHub Actions для автоматизации сборки
- XcodeGen для генерации проекта Xcode в среде сборки

## 🔧 Сборка

Сборка настроена через GitHub Actions. Подробности о шагах и параметрах следует сверять с актуальным файлом [сценария сборки](.github/workflows/build.yml) и [конфигурацией проекта](project.yml).

Для локальной сборки понадобится macOS с совместимой версией Xcode и необходимые инструменты Apple. Не меняйте идентификаторы, ресурсы и параметры подписи без понимания последствий.

## 🔐 Разрешения и доступность

Некоторым экспериментам могут требоваться разрешения iOS или поддержка конкретного оборудования. Отказ в разрешении либо отсутствие датчика могут ограничивать соответствующий сценарий, но не означают, что все остальные функции приложения недоступны.

## 🧩 Место в экосистеме

GeraKLab — самостоятельный проект экосистемы GeraK. Он описан в [GeraKProtocol](https://github.com/gkuhtov/GeraKProtocol), который служит документацией и не является программной зависимостью приложения.
